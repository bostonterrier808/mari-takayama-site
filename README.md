# Mari Takayama — Website

ニューヨークを拠点に活動するバレエダンサー、Mari Takayama のホームページです。

## ファイル

- `index.html` … サイト本体（これ1つで完結しています）
- `img/` … 写真
- `AGENTS.md` … Codex 向けのルール（Claude Code も `CLAUDE.md` 経由で同じルールを読みます）

## 共同編集の手順

1. 編集を始める前に、最新版を取り込む（`git pull`）
2. AI（Claude Code / Codex）に変更を頼む
3. ブラウザで `index.html` を開いて確認する
4. 終わったらすぐ保存して送る（commit → `git push`）

同じ箇所を同時に直すとぶつかるので、作業前に「今から写真を差し替えるね」など一言伝えると安心です。
